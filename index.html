03 — Architecture
How the agent is built.
Agent Core
Synchronous conversation loop with OpenAI-format tool calling. Provider-agnostic — Anthropic, OpenAI, OpenRouter, custom. Smart model routing with automatic failover.
Tool Registry
Pluggable tool system. Each tool self-registers schema + handler + availability check. Tools discoverable at import time. Agent-level interception for memory/todo.
Skill System
176 domain-specific skills as markdown knowledge bases. Trigger-condition matching. Linked references, templates, scripts. Auto-patching on discovery of errors.
Gateway Layer
Multi-platform messaging — Telegram, Discord, Slack, Feishu, Signal, WhatsApp, Home Assistant. Bidirectional. Session persistence. Token-lock for multi-profile safety.
Memory Stack
Dual-layer: durable facts (injected every turn) + session transcripts (FTS5 search). User profile separation. Automatic context compression on overflow.
Execution Layer
Cron scheduler with LLM-driven and no-agent modes. Background process registry. Sub-agent delegation with isolated terminal sessions. Windows desktop agent bridge.
